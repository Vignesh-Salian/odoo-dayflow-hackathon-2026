# 5-Minute Hackathon Demo Script Template

> **Strict Rule**: Maximum 5 minutes. Show only the functional flow, real data, and business value. No slide fatigue, no reading raw code.

---

## ?? Video Timeline Breakdown

```
[0:00 - 0:45] ??> 1. Problem & Context

[4:15 - 5:00] ??> 5. Output, Impact & Conclusion
```

## ?? Step-by-Step Script

### 1. Problem Statement (0:00 - 0:45)
* **Speaker**: [Dev 1 / Presenter]
* **Visual**: Clean dashboard / Opening title with problem banner
* **Script**:
  > "Hello evaluators! Today, [User Group] faces a major bottleneck: [Explain the core pain point in 2 sentences]. Existing manual processes cause [Error / Delay / High Cost]. To solve this, we built **[Project Name]**."

### 2. The Solution (0:45 - 1:15)
* **Visual**: Clean, modern application landing / dashboard
* **Script**:
  > "**[Project Name]** is a streamlined, intelligent platform that enables [User] to [Core Action] in real-time, reducing processing time from hours to seconds."

### 3. Main User Flow & Core Functionality (1:15 - 3:15)
* **Visual**: Live screen recording of real data input and immediate response
* **Script**:
  > "Let's walk through the live workflow:
  > 1. First, the user inputs [Data / Config / Document] here... *(Show form validation / upload)*
  > 2. The system instantly parses and validates the data against business rules... *(Show instant feedback)*
  > 3. Here on the dashboard, we see the generated records categorized with live status badges... *(Show Table / Card view)*
  > 4. The user can filter, inspect details in this modal, and trigger instant status updates."

### 4. Differentiating Feature / AI Insights (3:15 - 4:15)
* **Visual**: The unique highlight feature in action (e.g. AI summary, smart recommendation, automated export)
* **Script**:
  > "What makes our solution unique is [Differentiator Name]. Instead of just storing data, our system analyzes [Metric / Pattern] using [AI / Custom Engine] and produces actionable recommendations right here." *(Demonstrate the result with concrete output)*

### 5. Outcome & Business Value (4:15 - 5:00)
* **Visual**: Summary report / Exported PDF/CSV / Metrics view
* **Script**:
  > "In summary, **[Project Name]** delivers:
  > - **Efficiency**: [Key quantitative metric, e.g. 80% faster turnaround]
  > - **Accuracy**: Automated validation preventing costly manual errors
  > - **Scalability**: Clean modular architecture built with FastAPI and React.
  > Thank you for your time!"

## ?? Demo Recording Best Practices
1. **Pre-seed Realistic Data**: Never demo with "test1", "asdf", or empty tables. Pre-populate 5-10 realistic items.
2. **Smooth Flow**: Record without pauses; if a mistake happens, re-record that 30-second section.
3. **Audio Clarity**: Use a quiet room and a clear microphone.
4. **Link Settings**: Double check YouTube video is set to **Unlisted** or Google Drive is set to **"Anyone with the link can view"**.
